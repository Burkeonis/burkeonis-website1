Why I built this.

For a long time I believed my life would change if something outside of me changed.

A different city. A different relationship. More money. Less pain. Another chance. Another escape.

But every time I started over, I brought the same person with me.

The same fears. The same anger. The same habits. The same excuses.

The problem wasn't that I kept ending up in the same place. The problem was that I carried myself there.

That realization changed everything. Not because it fixed my life overnight, but because it left me nowhere to hide.
